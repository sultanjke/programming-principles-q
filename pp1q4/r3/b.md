# Problem B 493473. First and Last Character

You're given a string **s**. Write a program that returns a new string consisting of the first and last characters of **s**.

## Input format
The first line consists of the string **s**. Be careful, **s** can contain spaces!

## Output format
Output the first and last characters of string **s**.

## Examples

### Input
Programming in C plus plus can be very enjoyable

### Output
Pe

### Input
Hello World

### Output
Hd

### Input
Students are learning enw concepts during every lecture

### Output
Se

## Input
the quick brown fox jumps over the lazy dog

## Output
tg
