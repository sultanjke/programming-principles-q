# Problem A: 493456. Floating point to smaller and larger Integer

Write a C++ program that reads a floating-point number *n* from the user and then prints two values: the smallest integer greater than or equal to the number and the largest integer less tan or equal to the number.

## Input format
A floating-point number **n**.

## Output format
Print two integers separated by a space:
- The smallest integer greater than or equal to **n**.
- The largest integer less than or equal to **n**.

## Examples

### Input
70881.1

### Output
70882 70881

### Input
-84159.1

### Output
-84159 -84160

### Input
72.013

### Output
73 72
