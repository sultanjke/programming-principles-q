# Problem C: 494376. MaxMinDifference

Given three integers, write a program that finds the difference between the maximum and minimum values.
Try to use the built-in functions:
- max(a, b) - returns the maximum of a and b
- min(a, b) - returns the minimum of a and b

## Input format
Three integers a, b, c (-1000 <= a,b,c <= 1000).

## Output format
Print one integer - the difference between the maximum and minimum values (max - min).

## Examples

### Input
5
10
3

### Output
7

### Input
-5
-2
-8

### Output
6
