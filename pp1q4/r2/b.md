# Problem B: 495292. Cube and square root.

You are given two integers a and b. Compute:
a^3 (the cube of a), as an integer;
root of b (the square root of b), as a floating-point number.

## Input format
Two integer a and b. (-10^5 <= a <= 10^5) nd (0 <= b <= 10^6)

## Output format
Print two values on one line separated by a space: a^3, then root of b. Use the default output format without any modfications.

## Examples

### Input
-3 2

### Output
-27 1.41421

### Input
5 3

### Output
125 1.73205

### Input
9 625

### Output
729 25

## Notes
- b may not be a perfect square. Use appropriate data types to store the results.
You can use the long long data type to store the result of a^3.
