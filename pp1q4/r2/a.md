# Problem A: 493189. Multiply array elements by a number

Given an array a consisting of n integers and an integer k, multiply every element of the array by k.

## Input format
The first line contains an integer n where 1 < n < 10000. The second line contains n integers - elements of the array a 9 (-10^5 <= a[i] <= 10^5). The third line contains an int k (-10^3 <= a[i] <= 10^3).

## Output format
Print the new elements of the array separated by a space.

## Examples

### Input
3
5 -1 -50
10

### Output
50 -10 -500

### Input
2
9 13
-6

### Output
-54 -78
