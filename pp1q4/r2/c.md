# Problem C: 494925. First Character Repetition

You're give a non-empty string *s*. Your task is to determine how many times the **first character** of the string appears in the whole string.

## Input format
A single non-empty string *s* (1 <= s.length() <= 100)

## Output format
Print YES if the first character occurs at least twice; otherwise - NO. Then, separating by a space, print *k* - the number of character occurrences.
