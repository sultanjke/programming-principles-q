# Problem C: 494026. Difference Between Elements and Their Indices.

Given an array of *n* integers, create a new array where each element at index *i* is the difference between the original element and its index.

## Input format
An integer n (1 <= n <= 100) followed by *n* integers on the next line.

## Output format
Print the new array as a list of integers.

## Examples

### Input
3
5 10 15

### Output
5 9 13

## Notes
- For the element 5 at index 0: $5 - 0 = $5.
- For the element 10 at index 1: $10 - 1 = $9.
- For the element 15 at index 2: $15 - 2 = $13
