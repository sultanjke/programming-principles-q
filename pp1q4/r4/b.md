# Problem B: 493478. Convert to Total Seconds

You're given **days**, **hours**, **minutes** and **seconds**. Convert this time into a single total number of seconds and print it.

## Input format
Four integers are given in a single lin: **days** **hours** **minutes** **seconds**

## Output format
Print one integer - the total number of seconds.

## Examples

### Input
1 2 30 15

### Output
95415

### Input
0 0 20 10

### Output
1210

### Input
0 0 5 0

### Output
300
