# Problem A: 493463. Compare count of a and b in a string.

Given a string *s* and two characters *a* and *b*, print how many times *a* and *b* appear in the string. Then, in the next line print "Yes" if *a* occurs more frequently than *b*, otherwise print "No".

## Input format
The first line contains a string *s*. The second line contains two characters *a* and *b*, separated by a space.

## Output format
In the first line two integers, the count of *a* and *b*. In the second line "Yes" or "No" if *a* occurs more than *b*.

## Examples

### Input
bpzgJYgoq Pb rg

### Output
1 0
yes

### Input
programming principles
b h

### Output
0 0
No
