# Problem 3: Count Numbers Divisible by c in Range \[a, b\]

You are given three integers a, b, and c.\
Count how many numbers in the interval from a to b (inclusive) are
divisible by c.

## Input format

Three integers: a b c

## Output format

Print one integer --- the count of numbers divisible by c.

## Example

### Input

1 10 2

### Output

5

## Explanation

A number x is divisible by c if:

x % c == 0

You must check all numbers from a to b.
