# Problem 2: Buying Tickets

You are given three integers:
1) how many dollars a person has\
2) exchange rate (1 dollar in tenge)\
3) ticket price in tenge

Determine if the person has enough money to buy the ticket.

## Input format

Three integers:\
dollars rate price

## Output format

If money is enough, print: Yes change

If money is not enough, print: No difference

(If not enough, the difference will be negative.)

## Examples

### Input

2 500 700

### Output

Yes 300

### Input

1 500 1000

### Output

No -500
