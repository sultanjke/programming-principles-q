# Problem 3: Sequence Starting from N

You are given two integers:
1) starting number n\
2) how many numbers to print

Print the sequence starting from n and increasing by 1.

## Input format

Two integers:\
n k

## Output format

Print k numbers starting from n.

## Examples

### Input

8 4

### Output

8 9 10 11

### Input

1 5

### Output

1 2 3 4 5
