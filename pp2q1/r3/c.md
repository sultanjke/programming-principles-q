# Problem C: Length of a String Without Spaces

You are given a string. Compute its length excluding all space
characters.

## Input format

A single line containing a string.

The string may contain:\
- uppercase and lowercase English letters\
- digits\
- spaces

The length of the string does not exceed 10\^5 characters.

## Output format

Print one integer --- the number of characters in the string excluding
spaces.

## Example

### Input

Hello World

### Output

10

## Explanation

To solve this problem:

1.  Read the entire input line as a string.\
2.  Ignore all space characters ' '.\
3.  Count the remaining characters.

Only the space character should be excluded.
