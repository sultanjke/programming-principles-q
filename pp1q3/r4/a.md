# Problem A: 486782. Hide given digits

You are given a string. Replace every digit with the character "#". Leave all other characters unchanged.

## Input format
One line containing the string (may include letters, digits, spaces, and punctuation). Where size of given is 1 < s ≤ 100.

## Output format
Print the string after replacements.

## Examples

### Input
+7 (777) 123-45-67

### Output
+# (###) ###-##-##

### Input
NoDigitsHere

### Output
NoDigitsHere

### Input
passw0rd123!

### Output
passw#rd###!
