# Problem C: 485314. Separate Even and Odd

Write a program that separates even and odd numbers from a list into two different vectors while preserving the original order of appearance. The program should read a specified number of integers and classify them accordingly.

## Input format
An integer followed by integers. The first integer n (1 < n < 100) indicates the number of elements in the list. The next n integers are the elements of the list.

## Output format
Two vectors: The first vector contains all even numbers. The second vector contains all odd numbers.

## Examples

### Input
5
1 2 3 4 5

### Output
2 4
1 3 5

### Input
6
10 15 20 25 30 35

### Output
10 20 30
15 25 35
