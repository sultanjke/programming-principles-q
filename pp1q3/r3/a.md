# Problem A: 484973. The First and The Last Even

Write a C++ program that reads n integers into a vector and then finds the first and the last even numbers from the vector. If there is only one even number, it is considered to be both the first and the last. If there are no even numbers, output two zeroes.

## Input format
The first line of input contains an integer n (1 < n < 105), the size of the vector. The next line contains integers ai (-105 < ai < 105) — the elements of the vector.

## Output format
The first and the last even numbers, separated by a space.

## Examples

### Input
2
-26 -95

### Output
-26 -26
