# Problem C: 486108. CountGreaterASCIl

Given a string and a single character, write a program that counts how many characters in the string have a greater ASCII value than the given character.

## Input format
The first line contains a string s (1 < s ≤ 100). The second line contains a single character ch.

## Output format
Print one integer - the number of characters in s whose ASClI code is greater than that of ch.

## Examples

### Input
hello
a

### Output
5

## Notes
- ASCII value of 'a' is 97. The string "hello" contains the characters: 'h' (104), 'e' (101), T' (108), I' (108), 'o' (111). All of these have ASCII values greater than 97, so the result is 5.
