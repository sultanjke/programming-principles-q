# Problem B: 485975. Middle Characters

You're given a string s. Your task is to write a function that takes this string and returns the middle characters of it. Then, output these middle characters to the terminal.
• If the string length is odd, print the single middle character.
• If the string length is even, print the two middle characters.

## Input format
A single line containing a non-empty string.

## Output format
Print the middle character(s) of the string.

## Examples

### Input
hello

### Output
l
