# Problem C: 485860. Exponentiation long to store the result.

Write a function power (base, exp) that calculates base**P (base raised to the power of exp). The function should handle non-negative integers for both base and exponent. You can use a loop to perform the exponentiation. Make sure to use long.

## Input format
Two integers separated by a single space: base (0 < base < 100) and exp (0 < exp < 9).

## Output format
Print the result of the exponentiation.

## Examples

### Input
2 3

### Output
8
