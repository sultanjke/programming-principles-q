# Problem A: 486230. Split String by Char

You are given a string s and a char c. Your task is to split s into parts using c as the delimiter. The resulting parts must be printed in order, separated by spaces.

## Input format
The first line contains the string s. It is guaranteed that it is non-empty. The length does not exceed 100. The second line contains the char c. Both string s and char c can contain letters, digits, and special symbols (a-z, A-Z, 0-9, -, -=, +, 1, /).

## Output format
Print all parts of the string s after splitting it by the char c, separated by a space.

## Examples

### Input
abc-def-ghi

### Output
abc def ghi
