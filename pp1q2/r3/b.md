# Problem B: 478486. Even-Odd Transformation

Given an array of in integers, transforn it according to the following rule:
- If the element is even, divide it by 2.
- If the element is odd, multiply it by 3 and add 1. After performing the transformation on all elements, output the resulting array.

## Input format
The first line contains an integer n. The second line contains n integers - the elements of the array.

## Output format
Print the transformed array (all elements separated by spaces).

## Examples

### Input
5
2 3 4 5 6

### Output
1 10 2 16 3
