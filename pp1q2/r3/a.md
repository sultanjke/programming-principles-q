# Problem A: 478638. Matching Positions in Three Arrays

You are given three arrays A, B, and C, each containing N integers. Your task is to determine how many positions have the same value in all three arrays - that is, where A[i] = B[i] = C[i].

## Input format
The first line contains an integer N(1 < N ≤ 104) - the number of elements in each array. The second line contains N integers - the elements of array A. Tie third line contains A integers - the elements of array B. The fourth line contains N integers - the elements of array C. (-10 ≤ A[i], B[i], C[i] ≤ 10).

## Output format
Print one integer - the number of positions where all three arrays have equal elements.

## Examples

### Input
3
1 2 3
1 5 3
1 7 3

### Output
2
