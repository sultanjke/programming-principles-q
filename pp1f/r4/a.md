# Problem A: 140275. Just sum it.

An easy problem for you. You are given an integer *N*. Sum the *N*, the previous number to *N* and the next number to *N*.

## Input format
Number *N* (-10000000 <= *N* <= 10000000).

## Output format
The specified sum.

## Examples

### Input
1

### Output
3

### Input
2

### Output
6

### Input
100

### Output
300

### Input
1000

### Output
3000

### Input
0

### Output
0
