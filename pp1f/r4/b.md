# Problem B: 497057. Temperature Rises

You are given daily temperatures for *n* days. Count how many times the temperature increases compared to the previous day. If *n* = 1, the answer is **0**. Equal temperatures do not count as a rise.

## Input format
The first line contains a integer *n* (1 <= *n* <= 1000). The second line contains *n* integers: $a_0, a_1, \ldots, a_{n-1}$ (-10^9 <= $a_i$ <= 10^9).

## Output format
Print a single integer - the number of temperature rises.

## Examples

### Input
6

-2 -1 0 -1 -1 -5

### Output
2

### Input
4

3 3 3 3

### Output
0
