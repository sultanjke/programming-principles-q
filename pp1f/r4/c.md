# Problem C: 486225. Remove Every K-th Character

You are given one string *s* and one integer *k*. Your task is to remove every *k*-th character from the string. If *k* is greater than the length of the string, the the string stays unchanged.

## Input format
The first line contains a string *s* (1 <= |s| <= 10^5) consisting of lowercase English letters. The second line contains one integer *k* (1 <= k <= 10^5).

## Output format
Print the new string after removing every *k*-th character.

## Examples

### Input
abcdefg

3

### Output
abdeg

### Input
helloworld

15

### Output
helloworld
