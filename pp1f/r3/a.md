# Problem A: 494929. Round and sum

You are given two real numbers *a* and *b*. Your task is to **round both numbers** to the nearest integers and output their sum.

## Input format
Two real numbers *a* and *b* (-10^5 ≤ *a*, *b* ≤ 10^5).

## Output format
Print one integer - the sum of the numbers.

## Examples

### Input
4.2 5.7

### Output
10

### Input
-3.49 -3.51

### Output
-7
