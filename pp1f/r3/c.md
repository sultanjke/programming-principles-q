# Problem C: 486145. Count Different Neighbor Pairs

You are given one string *s* that contains only lowercase English letters. Your task is to count how many pairs of **neighbor characters** in this string are different. Two characters are called neighbors if they stand next to each other in the string.

## Input format
A single string *s* (1 <= s.length() <= 10^4) containing only lowercase English letters.

## Output format
Print one integer - the number of neighbor pairs in which the two characters are different.

## Examples

### Input
abdcab

### Output
5

### Input
abcda

### Output
4

### Input
aaaa

### Output
0
