# Problem C: 497051. Compare the Counts of Two Characters

Given a string *s* and two characters *a* and *b*, count how many times *a* and *b* appear in the string. Then, if the character *a* appears more frequently, output it to the terminal. Otherwise, if their counts are equal or char *b* is more frequent, output *b*. **Important:** Make sure you use an appropriate way to inpu a string containing spaces.

## Input format
The first line contains a string *s* that might have space characters. The second line contains two characters *a* and *b*, separated by a space.

## Output format
Character *a* if *a* occurs more than *b*; otherwise, character *b*.

## Examples

### Input
bpzgJYgoq pB rg

z a

### Output
z

### Input
programming principles

b h

### Output
h
