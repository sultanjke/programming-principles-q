# Problem B: 494882. We divided an orange

You are given a positive integer *N*. Your task is to determine how many times you can divide it by 2 before it becomes 0.

## Input format
A single integer *N* (1 ≤ N ≤ 10^9).

## Output format
Print a single integer - the number of divisions by 2 until *N* becomes 0.

## Examples

### Input
8

### Output
4

### Input
1

### Output
1

### Input
2

### Output
2

### Input
16

### Output
5
