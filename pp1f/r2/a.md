# Problem A: 497053. Absolute sum of two integers

Given two integers, *a* and *b*, find their absolute sum, that is, *abs(a + b)*

## Input format
Integers *a* and *b* - (10^5 ≤ a, b ≤ 10^5).

## Output format
The absolute sum of *a* and *b*.

## Examples

### Input
66 -93

### Output
27

### Input
-62 -31

### Output
93
