## Structure & naming

- `pp1` = course/subject (Programming Principles 1)
- `q4` = quiz/exam number
- `r2`, `r3`, `r4` = variant folders for the same quiz (different versions/runs)

So a folder like `pp1q4/` reads as: **PP1 → Quiz 4**.
